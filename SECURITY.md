# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < latest| :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly:

- **Do not** open a public GitHub issue for security vulnerabilities.
- Email **[your-security-email@example.com]** with details of the vulnerability.
- Include steps to reproduce, affected versions, and potential impact if known.

You should expect an initial response within **5 business days**. We will keep you
updated as we investigate and work on a fix.

## Disclosure Policy

- We ask that you give us a reasonable amount of time to address the issue before
  any public disclosure.
- Once a fix is released, we will credit reporters (unless anonymity is requested)
  in the release notes.

## Scope

This policy applies to the code in this repository. Vulnerabilities in third-party
dependencies should be reported to their respective maintainers.

## Preferred Languages

We prefer all communications to be in English.
